# SGI-ISN — Sistema de Gestão de Inventário e Atendimento Assistencial

MVP desenvolvido para otimizar o controle de estoque, monitorar prazos de validade e agilizar o atendimento presencial de famílias vulneráveis no **Instituto de Ação Social Sol Nascente (ISN)**.

## Vínculo com os ODS
* **ODS 2 — Fome Zero e Agricultura Sustentável:** Redução do desperdício de alimentos e insumos por meio de alertas automatizados de vencimento.

## Stack Tecnológica
* **Linguagem:** Python 3.12 | **Framework:** Django 5.0 | **Banco:** SQLite 3
* **Acessibilidade:** WCAG 2.1 AA (áreas de toque ≥ 48px e alertas multicanal)
